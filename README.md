## 構成

| | |
|---|---|
| `index.html` | `build.sh` が生成する。**中身は `game/battle/`。直接編集しない** |
| `game/battle/` | 戦闘画面（案E「二段」）。`head.html` ＋ `app.html` を組んで作る |
| `game/README.md` | 試作版の決めごと |
| `old/index.html` | 元のゲーム。`build.sh` が `prototype/` から生成する |
| `prototype/` | 元のゲームの原本（HTML 断片）。参考用 |

| `DESIGN.md` | 設計記録。判断とその理由、実測値 |

何か直したら `./build.sh` を実行してから commit する。

## 参考用のカジノルーレット（ゲーム本体とは無関係）

本物のヨーロピアンルーレットを、ゲームからの流用なしで別に作ったもの。
盤の並び・156 箇所の賭け・控除率 1/37 はすべて実物どおり。

| ファイル | 中身 |
|---|---|
| `roulette/` | 2D。(角度, 半径) で解く。玉がリムを離れる条件は `ω² = (g/r)·tanα`（Small & Tse, Chaos 2012） |
| `roulette3d/` | 3D。玉を 3 次元の質点として、盤の面との接触だけを解く。透視投影・自前レンダラ |
| `roulette-top/` | 物理は 3D のまま、絵だけ斜投影の 2D に落とす。仰角 68° 固定 |
| `roulette-dot/` | 俯瞰版をドット風にしたもの。仰角 56°、横 300 ドット・44 色。**玉を 1〜6 個同時に投げられる** |
| `wheel/` | 区画の**数・中身・色を差し替えられる**版。賭けは無し、投げて結果が出るまで。ゲームに組み込む前段階 |

それぞれ `<repo>/roulette/` のように直接開ける。各ディレクトリの README に、
どう解いているか・何を測ったか・どこで間違えたかを書いてある。
