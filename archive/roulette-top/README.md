# Roulette — 俯瞰

**物理は 3D 版とまったく同じ。**絵の落とし方だけが違う。
透視投影をやめ、視線の仰角を **68° に固定した斜投影**にしてある。

```
画面x = x
画面y = y·sin E − z·cos E          （E = 68°、+y は画面下）
```

遠近が付かないので、盤は「上から見た円」を一度描いて貼るだけで済み、
数字も潰れずに読める。高さ z は**画面上への持ち上げ**として出る。

## どこが 2 次元で、どこが 3 次元か

| もの | 扱い |
|---|---|
| 玉の運動 | **3 次元**。位置 (x,y,z)・速度 (vx,vy,vz) |
| 盤の鉢 | 高さ違いの**楕円を外から内へ塗るだけ**。輪ごとに `z·cos E` だけ上へずらす |
| ポケット帯 | `z = 0` の水平面なので、真上から焼いた図を**潰して回して貼る**だけで正しい |
| 玉 | 直交投影なので球は円のまま。`z` は上への持ち上げ |
| 影 | 玉の真下の面 `surfZ(r)` に落とす。浮くほど薄く大きくなる |

## 落とし穴

**水平成分の y を反転してはいけない。**
反転すると (1) 区画の並びが左回りになって実物と逆になり、
(2) 「潰して回して貼る」ポケット帯と玉が逆向きに回って、
止まった区画と発表がずれる。実際 30 回中 12 回ずれた。
canvas の向き（+y が画面下）に合わせるのが正しい。

斜投影は線形写像なので、**回転と潰しは交換できない**。
`scale(1, sinE)` を外側、`rotate(tr)` を内側にする。

## 検算

- 出目の一様性 χ² = 38.9 / 自由度 36（95% 上限 50.998）
- 賭け 156 箇所すべてが自分の座標で選ばれる／数字の中央は必ずストレート
- **玉を描かずに描き直し、玉のいる場所の画素を読んで、
  そこに描かれている区画の色と発表された数字の色が一致することを 30 回確認**
- 6 解像度で横のはみ出し無し
