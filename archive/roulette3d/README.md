# Roulette 3D

`roulette/`（2D 版）とは別物の、玉を **3 次元の質点**として解くルーレット。
盤の事実（区画の並び・赤黒・寸法・配当）と卓の作りは 2D 版と同じ。
違うのは物理と描画。

## 2D 版との違い

| | 2D 版 | 3D 版 |
|---|---|---|
| 玉の状態 | 角度・半径 | 位置 (x,y,z)・速度 (vx,vy,vz) |
| トラック離脱 | `ω² = (g/r)·tanα` という**条件式** | 条件を書かない。**接触が切れた結果**として落ちる |
| 跳ね | 半径方向の擬似的な弾み | 面との法線速度から反発係数で解く。宙に浮く |
| ディフレクタ | 角度が近ければ命中 | 球―球の 3 次元衝突 |
| フレット | 角度が近ければ跳ね返る | 高さを持つ壁。玉が上を越えれば当たらない |

## 1 ステップで解くこと（DT = 1/1500 s）

重力で速度を進め、位置を進めてから、順に接触を解く。

1. **垂直の壁**（r = 340 mm）— 速い玉はここに押しつけられて走る
2. **回転面** — 法線 `n = (−s·e_r, 1)/√(1+s²)`、`s = dz/dr`
3. **ディフレクタ** — 8 個の突起を球で近似
4. **フレット** — ロータと一緒に回る仕切り。相対速度で跳ね返す
5. **収まり** — ロータに対する速度が 0.22 m/s を下回った状態が 0.12 秒続いたら

### 摩擦の使い分けが要点

法線速度が 0.25 m/s を超えていれば**叩きつけ**（反発 0.42・μ=0.25）、
下回っていれば**載っているだけ**（反発 0.05・μ=0.010）。

**転がっている玉に滑り摩擦を毎ステップかけると、玉は 3 秒で止まる。**
最初これをやって「3.4 秒・トラック 5 周」になった。実物は 10 秒以上・20 周走る。
転がり抵抗は別に、角減速が一定になるよう接線方向へ入れている。

## 描画

ライブラリは使っていない。盤は回転面なので、帯に切って四角形の列にし、
透視投影して**奥から順に塗る**（画家のアルゴリズム）だけ。
玉と影も同じ列に混ぜて並べるので、奥にあるときは自然に縁へ隠れる。
数字だけは面に貼らず、投影した位置に画面座標で描いている。

ドラッグで視点、ホイールで寄り引き。

## 検算

- 6000 回：χ² = 38.3 / 自由度 36（95% 上限 50.998）、打ち切り 0
- 平均 10.9 秒・トラック 17.3 周（実機は 9〜14 秒・15〜25 周）
- 機械投擲：χ² が 5 桁、連続 9 区画に **94.6%** が集中（一様なら 24.3%）
- **玉を描かずに描き直し、玉のいる場所の画素を読んで、
  そこに描かれている区画の色と発表された数字の色が一致することを 30 回確認**
