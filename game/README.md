## ui-demo — 戦闘画面のレイアウト案

横画面 `1280×720` で組んで、入る幅に縮めて出している。
左にルーレット。**いまは `wheel/` を写した静止画を貼ってあるだけ**で、回らない。

4 案とも**同じ盤面**（同じ敵 3 体・同じ杖 5 枚・同じステータス）を出している。
違うのは並べ方だけなので、そのまま見比べられる。

| | 名前 | 何が違うか |
|---|---|---|
| A | 卓 | ルーレットと戦闘を同じ台の上に置く。敵も札も同じフェルトの上 |
| B | 機械 | 盤を機械に嵌め、右を計器盤にする。枠がはっきり分かれる |
| C | 舞台 | 右を横から見た舞台に。奥へ行くほど上に小さく並ぶ |
| D | 巻物 | 杖を縦に置く。上から下へ読む順＝詠唱の順 |

それぞれの「効くところ／弱いところ」は画面の上に出してある。

### 決めごと（4 案に共通）

| | |
|---|---|
| 文字 | **DotGothic16**（Google Fonts の日本語ドット書体）。前の版のように漢字を焼く仕組みは要らなくなった |
| 色 | 16 色だけ。ルーレットと同じ系統にして、ひと続きの世界に見せる |
| 角 | 丸めない。影は 3px ずらしの真っ黒（`box-shadow:3px 3px 0`） |
| ドット絵 | 14×14 の文字列の格子から `<svg>` の矩形を起こす。同じ色は横につないで矩形を減らす |
| 敵の名前と数字 | **同じ行に並べる**。重ねると必ずどちらかが読めなくなる（最初そうしていた） |

### 舞台（案C）の床

奥行きは**帯の境目＝その列の足元の線**として置いてある。
足元は `y + 25 + 14×px` で決まるので、帯の境目に合わせないと敵が床から浮く。
手前 492 / 中 455 / 奥 412 の 3 本。

### 検算

`dshot.js` と `dfit.js`。

- 4 案とも `1280×720` の外に出ている要素なし
- 例外なし
- 1600 / 1100 / 820 / 430 の幅で、横あふれ 0・枠と画面の高さが一致
