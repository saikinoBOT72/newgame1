## ui-demo — 戦闘画面のレイアウト案

横画面 `1280×720` で組んで、入る幅に縮めて出している。
**Dungeon Clawler の骨格**をそのまま借りた。

| | |
|---|---|
| ① | 抽選機（ルーレット）が画面の主役。**横幅の 47%**（598px） |
| ② | 自分と敵が 1 本の地面の線に立つ。自分は盤の下、敵は盤の右下 |
| ③ | 右端に細い操作レール（ターンをスキップ／丸い実行ボタン／小さい四角の並び） |
| ④ | 敵の次の一手は頭の上にアイコンで出す |
| ⑤ | HP は足元。盾は HP バーの左に紋章で付ける |

**札の入れ替えは廃止**したので、出た札は「どれが出たか分かるだけ」の大きさ。
修飾は次の発射体に乗るので、**乗るかたまりを破線で囲って**ひと続きに見せる。

4 案とも同じ盤面を出す。違うのは**出た札をどこに置くか**だけ。

| | 名前 | 出た札の置き場 |
|---|---|---|
| A | レール | 右のレールに縦一列 |
| B | 横 | 盤の右にできる縦の空き（ほかの案では余っている場所） |
| C | 受け皿 | 筐体の中、ガラスの下の受け皿（Dungeon Clawler のコンベアと同じ位置） |
| D | 下帯 | 画面のいちばん下に全幅の帯 |

### 盤の画像について

`wheel/` の盤を**裏画面 300 ドットのちょうど 2 倍（598×498）で焼いた**もの。
2 倍ちょうどにしないとドットが 2px と 3px に割れて、拡大が汚くなる。
64 色に量子化して 18KB。**まだ回らない。静止画。**

### 決めごと

| | |
|---|---|
| 文字 | **DotGothic16**（Google Fonts の日本語ドット書体）。漢字を焼く仕組みは要らなくなった |
| 色 | 16 色だけ。ルーレットと同じ系統 |
| 角 | 丸めない。影は 3px ずらしの真っ黒 |
| ドット絵 | 14×14 の文字列の格子から SVG の矩形を起こす。同じ色は横につないで矩形を減らす |
| 地面に物を置かない | 樽を置いてみたら敵の立ち位置とちょうど重なった。地面は敵の場所 |
| 見出しは札の左 | 囲みの上に置くと、破線と文字がぶつかる |

### 検算

`dshot.js` と `dfit.js`。

- 4 案とも `1280×720` の外に出ている要素なし
- 例外なし
- 1600 / 1100 / 820 / 430 の幅で、横あふれ 0・枠と画面の高さが一致
