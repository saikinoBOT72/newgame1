# battle — 戦闘画面（案B「横」で確定）

見た目だけ。機能は一切入っていない。盤も回らない（`wheel/` を焼いた静止画）。

## いちばん大事な決めごと

**画面ぜんぶを仮想 640×360 のドットで組んで、最後に整数倍で拡大する。**

盤の裏画面が 300×250 なので、仮想画面ではそれが等倍で置ける。
こうすると盤のドット・人物のドット・枠線・文字が**ぜんぶ同じ大きさの升目に乗る**。

素人くさく見える最大の原因はここが揃っていないこと。
前の版は盤 2px・人物 6px・枠線 3px・文字は任意サイズで、**格子が 4 種類**あった。
目はそれを「解像度の違うものを貼り合わせた」と読む。
盤が浮いて見えたのは配置のせいではなく、これが原因。

## 素人くさく見える原因として潰したもの

### 格子

| | |
|---|---|
| 格子の混在 | 仮想 640×360 の 1 つの升目に統一 |
| 半端な拡大 | **整数倍だけ**。1.5 倍だとドットが 2px と 3px に割れる。入りきらないぶんは中央に置いて余白にする |
| 小数の座標 | 全部整数 |
| 文字が升目に乗らない | ドット書体を**設計サイズの整数倍**でしか使わない（DotGothic16 は 16px 設計 → 仮想 8 ドット） |

### にじみ

| | |
|---|---|
| 角丸・ぼかし影・なめらかな階調 | 全部やめて**順序ディザ（4×4 ベイヤー）**で段を作る。壁の明暗も機械の光もディザ |
| 斜め線のアンチエイリアス | 回転で作らず**1 ドットずつ階段で刻む**（ガラスの映り込み） |
| 半透明の重ね | 中間色が無限に増えるので、ディザで代用 |

### 色と光

| | |
|---|---|
| 要素ごとに色を選ぶ | 色相ごとの**段（ramp）**で持ち、段からしか選ばない |
| 影がただのグレー | 影は環境の寒色、光は光源の暖色に寄せる |
| 光の向きがばらばら | 全部の凹凸を**左上から**に統一。上と左が 1 ドット明るく、下と右が 1 ドット暗い |
| 奥も手前も同じコントラスト | 奥（上）の石積みはコントラストを落とす |

### ドット絵

| | |
|---|---|
| 平坦な塗り | 形を置いたあと**機械的に陰影を付ける**（空いている側が上か左なら 1 段明るく、下か右なら 1 段暗く） |
| 輪郭が無い／純黒 | **その色相のいちばん暗い段**で縁取る |
| 接地が曖昧 | 人物に硬い接地影、機械と棚に硬い落ち影。ぼかさない |
| 小さすぎる | 機械と敵の大きさの比を Dungeon Clawler に合わせた（7.3:1 → 3.5:1）。形の座標ごと 1.5 倍にしてから升目に起こす（SVG を引き伸ばすと格子が壊れる） |

### 「貼り付けた感」

| | |
|---|---|
| 因果の線が無い | 盤 → **管** → 棚、と札の通り道を描く。無いと札は「どこかから湧いた」ことになる |
| 取り付けが無い | ガラスの奥に沈め、四隅を**ボルト**で留める |
| 素材の語彙が違う | 機械・棚・右のレールを**同じ木と真鍮**で、同じ面の作り方で組む |
| 周りが反応しない | 機械の明かりが壁と床を照らす（これもディザ） |
| 操作が世界から浮く | 丸いボタンをやめ、**床に立って機械につながるレバー**にした。軸を機械の下枠まで通してある |

### 版面

| | |
|---|---|
| 枠の太さが全部同じ | 世界（壁・床・人物）に枠は無く、機械と HUD にだけ枠がある |
| 数字だけで状態を出す | 記号・数字・色の 3 つで出す（HP・盾・次の一手） |
| 揃えが混ざる | 見出しは左、数字は右 |
| どこを見ればいいか無い | 前の敵に印、**次の一手**を右のレールに 1 か所だけ |
| 壁と床が同じ素材 | 床は石ではなく木。material を変えないと床が壁の続きに見える |

## 中身

| | |
|---|---|
| 機械 | `x 4..316`。ガラスの中に盤（300×250）。四隅にボルト |
| 管 | 機械の右から棚の上へ。送りの向きを 3 つの点で示す |
| 棚 | `x 356..496`。壁に金具で掛かっている。**修飾は真鍮の棒で束ねて「これで 1 発」を形で示す** |
| レバー | 床に立ち、軸が機械の下枠へ入る |
| 地面 | 足元 `y 332`。自分も敵も同じ線に立つ |
| レール | `x 504..640`。ターンをスキップ／玉の数／持ち物・図鑑・相棒／読み取り／次の一手 |

## 検算

`bshot.js`（枠外に出ていないか・例外）と `bfit.js`（拡大が整数倍か・横あふれ）。

- 640×360 の外に出ている要素なし（意図してはみ出す壁と光は除く）
- 例外なし
- 幅 1400 → ×2、1100 → ×1、820 → ×1、430 → 端数（640 より狭いときだけ許す）

盤は回らない。ボタンは押せるように見えるが何も起きない。数字も文言も仮。
