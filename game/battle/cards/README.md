# cards — 札の絵

**ここに PNG を置くと札の絵になる。**`build.py` が拾って、表示する大きさに
落としてから `app.html` に埋め込む。

## 決めごと

| | |
|---|---|
| ファイル名 | そのまま札の **id**。`sword.png` → `sword`。コード側は `CARD_IMG.sword` で参照する |
| 大きさ | 比が **7:5（縦長）**であればよい。表示は 110×154。いまの絵は 836×1195 |
| 余白 | キャンバスの端の透明な余白は自動で落とす。付けたままでよい |
| 名前と効果 | **絵には書かない。**空の帯のままにする |
| 色 | 丸めない。送られたままの色で埋め込む |

## 名前と効果を絵に焼かない理由

字を絵に焼き込むと、110×154 に落とした時点で 8 ドットに潰れて読めない。
文字は札の上に HTML で重ねている（`handCard()`）。重ねる位置は
テンプレートの帯に合わせてあるので、**帯の位置が変わると文字もずれる**。

| | 札の中の位置（110×154 のとき） |
|---|---|
| 名前の帯 | `x 6..102, y 11..21` |
| 効果の帯 | `x 11..99, y 109..143` |

## 絵を足すときに、絵とは別に要るもの

`src/b_game.txt` の `DECK` に 1 行。絵だけでは札にならない。

```js
{id:"torch", el:"fire", nm:"ボロ松明", fx:"最前の敵に炎上3",
 n:3, img:CARD_IMG.torch, act:{tgt:"front", burn:3}},
```

| | |
|---|---|
| `el` | 属性。`norm` / `fire` / `ice` / `poi`。**盤の区画の色はここから決まる** |
| `n` | 盤に置く区画の数。そのまま出る確率になる |
| `act.tgt` | `front`（最前）/ `back`（最後）/ `all`（全体） |
| `act.dmg` | ダメージ |
| `act.burn` | 炎上を積む |
| `act.brk` | 盾を割ってから当てる |
