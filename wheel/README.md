# 差し替えルーレット

区画の**数・中身・色**を差し替えられるルーレット。ゲームに組み込む前段階のもの。
ドット版（`roulette-dot/`）から**物理と絵はそのまま**持ってきて、**賭けと配当を落とした**。
投げる → 結果が出る、まで。

## 差し替えられるもの

| | |
|---|---|
| 区画の数 | 2 〜 46。上限は後述（玉が入るかどうかで決まる） |
| ラベル | 各区画に 6 文字まで。空でもよく、同じ文字が何個あってもよい。同じラベルが並ぶときのために、結果は区画の番号も出す |
| 色 | 見本から選ぶ。見本は**丸め先の色表に入っている色だけ**にしてある |
| 並び | まぜられる。出目の確率には効かないが、機械投擲（初期条件を固定）にすると隣り合う区画に固まって出るので効いてくる |

ひな型：ヨーロピアン 37 / アメリカン 38 / 赤黒 24 / 均等 12 / 札 6 枚 / 当たり 1・外れ 11。

## 数を変えても壊れないようにした場所

| | |
|---|---|
| 区画の位置 | `pocketStart / pocketAt / pocketCentre` の 3 つだけが決める。`SLOT = 2π/N` を定数に焼かず、毎回この 3 つを通す |
| フレット | 物理側も、区画の位置と**同じ位相**で近いフレットを探す（`norm(ph − tr − ROTOR_PHASE)`） |
| ポケット帯の絵 | 差し替えのたびに焼き直す。角度は玉と同じ `pocketStart` から取る |
| ラベルの字 | 区画の弧長を測って、入るまで縮める。5 px を切るなら書かない。下地の明るさで白と黒を選ぶ |
| 統計 | 自由度は `N−1`。95% 上限は表を持たず Wilson–Hilferty 近似で毎回出す。数え器も作り直す |
| 差し替えの禁止 | 玉が転がっている間は編集できない。途中で作り変えると、いま転がっている玉がどの区画にいるのか決められない |
| 色 | 持つ前に**丸め先の色へ寄せる**（`snapColour`）。寄せないと「選んだ色」と「出ている色」が食い違う |

### 色を寄せる話

絵は 44 色へ丸めてから引き伸ばす。丸めは `32×32×32` の引き当て表で引くので、
**表に入っている色でも、丸めると別の色になることがある**。
たとえば `#101013`（黒の区画）は `#171310` になる。8 段に落とした升目の中心が、
そちらに近いため。持つ前に寄せておけば、選んだ色と出ている色が必ず一致する。

これはドット版でも起きていた（黒の区画が `#171310` で描かれていた）。
色が黒どうしで見分けがつかないので気づかなかった。

## 区画の数の上限は、玉が入るかどうかで決まる

上限を「なんとなく 50」と置くと、その手前で玉が収まらなくなる。
決めているのは幾何のほう。

| | |
|---|---|
| 玉の直径 | 21.0 mm |
| ポケット帯の内側の円周 | `2π × 196 mm = 1232 mm` |
| 1 区画の幅 | `1232 / N mm` |
| 実物（N=37） | 33.3 mm ＝ 玉の直径の **1.58 倍** |
| 上限 | 玉の直径の **1.25 倍**を切らせない → `N ≤ 46` |

これを割ると、玉は両側のフレットから同時に押し返されて振動し、収まらない。
41 区画から上は「入るには入るが収まるまでが長い」ので注意だけ出す。

**上限が正しい位置にあることの確かめ方**：玉が止まった位置から、いちばん近い
仕切りまでの距離を測る。玉が区画の中に入っていれば、この距離は幾何が決める
下限 `R / (SLOT·r)` を下回れない。

| N | 幅比 | 実測の最小 | 幾何の下限 |
|---|---|---|---|
| 37 | 1.58 | 0.280 | 0.277 |
| 46 | 1.27 | 0.354 | 0.345 |

3 桁一致する。上限を外して 70 区画（幅比 0.84）にすると、玉は仕切りの上に
乗ってしまい、この関係が崩れる。

## 確率について

盤が偏っていなければ、どの区画も `1/N`。
区画の**数**で確率が決まるので、「同じ中身の区画を 2 つ置く」のが重みの付け方になる。
当たりを 2 倍出したければ、当たりの区画を 2 つ置く。
ラベルが同じでも別の区画として数えるので、統計の棒グラフでは別々に立つ。

## 検算

`wpixel.js`（ブラウザ）と `wm.js`（node で物理だけ）で見ている。

- 区画 2〜46 のどれでも、盤に塗られた色が中身と 1 対 1 で一致（185 点 × 9 通り）
- 区画 2/7/19/37/46 で、収まった玉はどのロータ角でも自分の区画の中。発表も一致
- 数の入力・±・シャッフル・ひな型のどれでも、盤と一覧と数え器がそろう
- 区画 2〜46 を 300 回ずつ回して、詰まり 0・位置ずれ 0

区画の数を変えて 300 回ずつ（1 玉 / 6 玉、18 秒で打ち切り）。

| 区画 | 幅比 | 1 玉 打ち切り | 6 玉 打ち切り（玉数） | 6 玉 中央秒 |
|---|---|---|---|---|
| 2 | 29.3 | 0 | 29 / 1800 | 13.1 |
| 4 | 14.7 | — | 14 / 1800 | 12.1 |
| 12 | 4.9 | 0 | 6 / 1800 | 12.0 |
| 37 | 1.58 | 0 | 1 / 1800 | 10.9 |
| 46 | 1.27 | 0 | 4 / 1800 | 11.0 |

どの区画数でも詰まり 0・位置ずれ 0。区画が少ないほど収まるのに時間がかかるのは、
仕切りが少なくて玉の勢いを削るものが無いため。物理としてはそうなる。
